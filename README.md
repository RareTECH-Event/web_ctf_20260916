# Web CTF

Webアプリケーションセキュリティ研修用のCTF教材です。ECサイト風アプリ「Web CTF」に仕込まれた10個の脆弱性を、ブラウザとターミナル（curl / Pythonなど）だけを使って攻略し、フラグ（`FLAG{...}`）を見つけてください。

**注意: ソースコードの閲覧・改変は行わないでください。** すべての問題は、HTTPリクエスト・Cookie・フォーム入力・URL操作・ブラウザの開発者ツールの範囲で攻略できるように作られています。
`docker exec` などでコンテナ内部に直接アクセスすることは、想定した攻略ルートではありません。



## 動作環境

- Docker Desktop（Mac / Windowsどちらでも可。Windowsの場合はWSL2バックエンドを利用してください）
- ブラウザ（Chrome, Firefoxなど）
- ターミナル（curlやPythonが使えると一部の問題で便利です）



## セットアップ

配布された以下の3点を、同じフォルダに置いてください。

- `web-ctf.tar`（アプリのDockerイメージ）
- `docker-compose.yml`
- `.env`（フラグ判定に必要な設定ファイル）

### 1. イメージを読み込む

ターミナルで配布フォルダに移動し、以下を実行します。

```
docker load -i web-ctf.tar
```

### 2. アプリを起動する

```
docker compose up
```

起動ログに `Running on http://0.0.0.0:8000` のような表示が出れば起動完了です。

### 3. アプリにアクセスする

ブラウザで以下のURLを開いてください。

```
http://localhost:8000
```

トップページが表示されれば準備完了です。

### 4. アプリを終了する

ターミナルで `Ctrl+C` を押すか、別のターミナルから以下を実行します。

```
docker compose down
```

**アプリはステートレスに作られており、再起動すると全データ（ログイン状態・カート・DBの内容など）が初期状態にリセットされます。** 問題を進める中で状態がおかしくなった場合は、`docker compose down` → `docker compose up` で最初からやり直せます。


## 困ったときは

- ポート `8000` が他のアプリで使われている場合は起動に失敗します。他のアプリを終了してみましょう。
- 何度実行しても状況が改善しない場合は `docker compose down` → `docker load -i web-ctf.tar` → `docker compose up` を試してください。
- それでも解決しない場合は講師に質問してください。
